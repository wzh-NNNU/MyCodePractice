# class001 笔记：语言转换示例

## 题面

本节用排序代码说明算法思路可以跨编程语言表达。示例文件包含 LeetCode「排序数组」接口，以及归并排序、随机快速排序和堆排序实现。排序数组长度最多按代码中的 `MAXN = 50001` 预留。

## 核心思路

- 归并排序采用自底向上的迭代写法：`step` 从 1 开始倍增，每轮将相邻有序段合并到辅助数组，再复制回原数组。
- 随机快速排序随机选取数组中的一个数作为枢轴，通过荷兰国旗分区把小于、等于和大于枢轴的元素分开，再递归处理两侧。
- 堆排序先从最后一个非叶子位置向前调整为大根堆，再反复交换堆顶和当前末尾元素，并缩小堆的有效范围。
- H 版根据 Java 代码直接转换为 C++，使用 `vector` 对应数组参数及辅助存储；N 版根据原算法结构实现，完全不使用 `vector`，改用静态数组。

## 坑点

- 归并每轮要检查 `m + 1 >= n`，否则右半段不存在；右边界需要限制在 `n - 1`。
- 快速排序分区时，大于枢轴的元素与 `last` 交换后，当前位置尚未检查，不能递增 `i`。
- 堆排序构建阶段从 `n - 1` 向前调用 `heapify` 也正确，只是会额外调整叶子节点。
- 静态数组容量必须覆盖题目最大输入规模；随机数使用前在测试入口调用 `srand(time(0))`。

## 代码

本课按项目约定提供两个版本：`01_语言转换H.cpp` 根据 Java 代码直接转换，使用 `vector`；`01_语言转换N.cpp` 根据原算法结构实现，不使用 `vector`，改用静态数组。完整代码分别见 [N 版](01_语言转换N.cpp) 和 [H 版](01_语言转换H.cpp)。

核心归并排序实现如下：

```cpp
void mergeSort(int nums[], int n) {
	for (int l, m, r, step = 1; step < n; step <<= 1) {
		l = 0;
		while (l < n) {
			m = l + step - 1;
			if (m + 1 >= n) {
				break;
			}
			r = min(l + (step << 1) - 1, n - 1);
			merge(nums, l, m, r);
			l = r + 1;
		}
	}
}

void merge(int nums[], int l, int m, int r) {
	int p1 = l, p2 = m + 1, i = l;
	while (p1 <= m && p2 <= r) {
		help[i++] = nums[p1] <= nums[p2] ? nums[p1++] : nums[p2++];
	}
	while (p1 <= m) help[i++] = nums[p1++];
	while (p2 <= r) help[i++] = nums[p2++];
	for (i = l; i <= r; i++) nums[i] = help[i];
}
```
